# GitHub Pages 作品集发布包

本文件夹包含静态展示页、PDF 和六页总览图，可作为 GitHub Pages 的网站根目录。

## 手动发布

1. 登录 GitHub，新建一个**公开仓库**。
2. 打开本文件夹，把里面的 `index.html`、`styles.css`、`print.css`、`app.js`、`assets` 文件夹和本说明上传到仓库根目录。不要把外层 `github-pages` 文件夹整体再套一层上传。
3. 上传完成后，点击 **Commit changes**。
4. 打开仓库的 **Settings → Pages**。
5. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，点击 **Save**。
6. 等待 GitHub Pages 部署完成。在 **Settings → Pages** 查看网站地址，或在仓库的 **Actions** 查看部署状态。

项目仓库的网站地址通常是 `https://你的用户名.github.io/仓库名/`。打开后可以浏览作品集，也可以查看页面中的 PDF 和总览图。

本展示页的数据是截至 2026-10-24 的静态快照，不会随飞书实时更新。仓库和网页为公开状态；发布前请确认展示内容及附件可以公开。飞书报表链接仍需使用有权限的飞书账号打开。
